- **QA Automation Framework**  
  Automated testing pipelines using Python and Selenium, integrated with GitHub Actions for CI/CD.

- **Customer Support Analytics Dashboard**

  *Key impact: Enabled data-driven decision-making and improved support KPIs.*

- **Gaming Performance Optimizer (Personal Project)**  
  Scripts and configurations for ROG Ally X and Apex Legends to enhance performance and streamline gameplay.  
  *Key impact: Improved FPS stability and reduced latency for competitive play.*
